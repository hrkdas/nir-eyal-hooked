# Reference 05: Investment — Stored Value & The Next Loop

> *"Unlike the physical world where things depreciate with use, habit-forming products appreciate in value the more users invest in them."* — Nir Eyal

---

## 1. The Psychology of the Investment Phase

The investment phase occurs **after** the user has received a variable reward. When users are in a state of dopamine afterglow, they are most receptive to putting a small bit of effort back into the service.

The investment phase leverages three cognitive biases:
1. **The IKEA Effect**: People irrationally overvalue things they helped create or assemble.
2. **Cognitive Dissonance Avoidance**: Users rationalize their past effort ("I spent 2 hours setting this up, therefore I must love it").
3. **Escalation of Commitment**: Small initial commitments naturally pave the way for larger ongoing commitments.

---

## 2. The 5 Types of Stored Value

| Stored Value Type | Mechanism | Switching Cost Impact |
| :--- | :--- | :--- |
| **1. Content** | Playlists, documents, articles, code repos, photo albums | Leaving means abandoning user creations. |
| **2. Data** | Watch history, financial transactions, fitness logs, personal analytics | Tailors the algorithm; leaving resets personal intelligence. |
| **3. Followers (Social Graph)** | Audience built, subscribers, contacts synced | High switching cost; cannot easily export audience to rival. |
| **4. Reputation** | Seller feedback, badges, karma, review histories | Social capital lock-in (e.g. Airbnb host score, eBay rating). |
| **5. Skill & Muscle Memory** | Keyboard shortcuts, tool workflows mastered | Cognitive switching barrier (e.g. mastering Vim, Excel, Figma). |

---

## 3. Loading the Next Trigger (Closing the Loop)

The most critical function of the Investment phase is **priming the next external trigger**:
* An investment that does not trigger a future prompt leads to a broken loop.
* *Example*: User tags a coworker in a document $\rightarrow$ Coworker receives notification $\rightarrow$ Coworker replies $\rightarrow$ Original user receives a notification.
* The investment automatically programs the next external cue, restarting the Hook cycle without company ad spend.
